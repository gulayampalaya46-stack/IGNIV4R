# IGNIVAR - Chapter 1 App Rebuild

This package contains the latest IGNIVAR Chapter 1 RPG with integrated backgrounds,
interactive map, and PWA files.

Files:
- index.html — game
- manifest.webmanifest — installable PWA configuration
- sw.js — offline/service-worker support
- icons/ — app icons

For GitHub Pages, upload the contents of this folder to the repository root.
